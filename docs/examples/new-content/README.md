# Example content, ready to copy

Each folder here matches a folder in `content/`. Copy a file across, build,
and it is in the game. Try them all at once to see a 13th stop (Siwa), a
new floor shape, a relic, two river events, a trial, something new at
Anubis's stall, a treasury upgrade, an amulet set and a floor set.

Some of them lean on each other: Siwa uses the `oasis` floor shape, the relic
is found at Siwa, and the rose-gold amulets are unlocked by the relic. The
build tells you if one is missing its partner.

Siwa brings its own pictures: copy `images/backdrops/siwa.svg` and
`images/boards/siwa.svg` from here into the game's `images/` folder too.

The manual (`docs/manual/part-1-making-things.md`) walks through each kind step by step, and
`engine/docs/content-reference.md` lists every field.
