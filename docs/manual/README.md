# The manual

Amulets of Anubis is built to be changed. The manual comes in two parts,
for two kinds of reader.

**[Part 1: Making things](part-1-making-things.md)** is for everyone. It
explains how the game is put together in plain words and how to change
pictures, words and numbers and add new stops, tombs, river events, relics,
boons and looks, with no programming. Its last chapters show how to check
that a change is fair and how to write a new kind of boon in a few lines of
code, step by step.

**[Part 2: The engine](../../engine/docs/manual/part-2-the-engine.md)**
is for programmers. It describes how the game works inside: the build, the
rules, the running game, the interface and its rules, sound and music,
saving, balance, performance and how to extend each part. It belongs to
the engine rather than to this game, so it can be found with the engine in
`engine/docs/` and comes along whenever the engine is updated. Its examples
are thus from the engine's own little example game rather than from the
Nile.

The whole manual is also a book to read or print:
**[the manual as a PDF](https://amuletsofanubis.com/amulets-of-anubis-manual.pdf)**
and on the website, with a search: [amuletsofanubis.com/manual.html](https://amuletsofanubis.com/manual.html).

Alongside them:

- **[A map of the code](../../engine/docs/code-map.md)**: what each file of
